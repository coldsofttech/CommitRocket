# Support

- **Start with the docs:** the [README](README.md) covers installing and using CommitRocket. For every option see the [command line guide](docs/guides/cli.md); for more detail see the [architecture notes](docs/architecture.md) and the [development guide](docs/development.md).
- **Check your setup:** run `commitrocket doctor`. It reports your Python, Git and git-lfs versions, your config file, whether the remote is reachable and where logs are kept.
- **Questions and ideas:** use [GitHub Discussions](../../discussions) if enabled, otherwise open an issue with the feature request form.
- **Bugs:** open an issue with the bug report form. Include the CommitRocket version (`commitrocket --version`), your operating system, your Python, Git and git-lfs versions, your Git host, the full command and the error output. The log file helps too; re-run with `--level DEBUG` and attach the relevant lines. Leave out tokens, credentials and private paths.
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not open a public issue.
